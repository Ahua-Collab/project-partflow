# 已知限制与验证边界

[English](limitations.en.md) · [阶梯工坊 · Stepwise](../README.md)

## 流程不是执行平台

技能是文字规则、模板与检查器，不是任务调度服务器。它没有自动创建窗口、跨宿主发消息、自动合并、联网接交易所或更改系统权限的独立能力。宿主可用工具与明确授权决定能否执行；没有工具可手工转发。

指令里的所有权不等于操作系统 ACL。总控和实现角色仍可能误读、遗漏或做错；独立审核降低风险，但不保证零幻觉、零缺陷、固定交付速度或固定 token 节省。

原生面向 Codex。使用其他 AI 工具时，需要使用者自行适配工具接口、角色派工、文件权限并验证；未测试现成兼容性。展示品牌不改变 `project-partflow` 技能标识。

## 检查器只覆盖部分结构

`gate.mjs` 校验配置、连续 Part、依赖、review 字段、证据文件存在、提交与主线祖先关系等。`ownership` 只覆盖两个提交间的已提交 diff 和配置所有权，不自动审未提交/未跟踪内容，也不推导 prompt 的更窄权限。

它不验证日志是否真实、命令是否确实产生该日志、证据正文是否对应声明、接口实现正确与否、需求是否合理。它不会执行产品测试，也不能发现所有被伪造但格式正确的记录。`inputs` 是指定根的局部路径/哈希索引，不认证该根是最新治理，不覆盖所有引用，不能充当已读证明。

脚本依赖本机 Git 对象与正确配置的主分支，浅克隆或缺失历史可能使祖先核验受阻。没有自动修复、自动迁移或跨会话有效的阅读缓存。

## 模板需要实例化

`assets/` 保留占位符、空映射和未通过状态。使用前依据认可需求和现场 Git 填写，不把模板的 Part=1、空任务表或布尔值当作结果。模板不是可直接运行的完整业务项目。

同角色多个任务需加任务 ID 后缀。已有项目的路径、分支、门禁与所有权按原治理发现，不能安装技能后静默覆盖。旧 Day/schema 1 必须按 [恢复说明](../references/recovery.md) 人工核对或经授权迁移。

## 验证范围

本次只验证发布包结构、链接、脱敏检查、原文件一致性，以及合成 Git 仓库上的检查器自测。实际环境与自测计数在 [验证说明](validation.md)。未验证所有产品代码、全部宿主操作、其他系统/工具版本、跨设备真实恢复、真实市场容量、账户操作或端到端交易。

匿名案例来自对协作记录的有限只读整理，没有把记录自报的产品测试重新执行或认证为本次实测。旧快照中的缺陷可能已有后续关闭证据；不能把教学例子当作任何真实项目当前状态。没有测量前后 token 消耗，也没有宣称节省百分比。

## 发布与许可

公开 skill 不等于公开使用它的项目。真实项目中的需求、私有契约、日志、聊天、数据与账户信息均不随包发布。发布审查是规则扫描和人工内容核对的组合，不是绝对不存在秘密的形式证明。

本副本未替权利人选择许可证；公开访问和开源许可是不同事项。身份核对、仓库归属与写权限在发布操作时另行确认，文档不内置账号或凭证。
